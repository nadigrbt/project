# Sayvo — памятка проекта

Рабочее название: **Sayvo**. Мобильный тренажёр английских слов для русскоязычных: карточки, умное повторение (FSRS), проверка произношения через распознавание речи на устройстве. Всё бесплатно, без своего сервера.

Эту памятку читают в начале каждой рабочей сессии. Держим её короткой и актуальной.

## Команда и роли
- Владелец проекта: nadigrbt — ставит задачи, принимает изменения, собирает и тестирует на телефонах, генерирует картинки.
- Claude — код, контент (слова, переводы, примеры), промпты картинок, тексты для магазинов, инструкции.
- Второй разработчик — проверка кода, сборки, сложные баги на устройствах.

## Стек
React Native + Expo (TypeScript, development build), expo-router, zustand, expo-sqlite + drizzle-orm, ts-fsrs, expo-speech-recognition (на устройстве: iOS 17+, Android 13+), expo-speech (озвучка), expo-notifications (только локальные), reanimated, jest, EAS Build.
Базы: `content.db` (только чтение, поставляется с приложением) и `user.db` (прогресс пользователя).

## Объём первого релиза (урезанный MVP)
Входит: карточка нового слова (T0), 3–4 типа упражнений, FSRS-повторение, проверка произношения (T7/T8, не влияют на оценку FSRS), экран «Сегодня», словарь, один набор «Путешествия», светлая и тёмная темы, локальные напоминания.
Позже: тест уровня (O4), импорт из текста (N5), подробная статистика, заморозки серии, редкие типы упражнений, iOS-релиз (сначала Android/RuStore).

## Правила проверки произношения
Совпадение с 1-м вариантом распознавания — 100, «Отлично». 2–3-й вариант — 80, «Почти». Отличие на одну фонему — 60 и подсказка по звуку. Фразы — совпадение ≥80% слов. Целевое слово в подсказки распознавателю не передаём.

## Картинки
Стиль: современная стилизованная полуобъёмная иллюстрация для взрослой аудитории, крупный план, один предмет, 4 фоновых цвета по темам, **никакого текста на картинке**. Два постоянных героя (сестра и брат). Промпты и скрипт сборки — `content/images/`.

## Порядок работы
- Каждая задача — новая сессия и отдельная ветка, изменения через pull request в `main`.
- Одна задача = один экран или один модуль.
- Замечания по сборке — одним списком, из логов только кусок с ошибкой.
