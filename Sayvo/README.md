# Sayvo

Рабочая папка мобильного тренажёра английских слов Sayvo.

- `CLAUDE.md` — памятка проекта: стек, объём MVP, цвета, правила, статус.
- `content/images/` — промпты для иллюстраций к словам (набор «Путешествия», 50 слов) и листы с героями.

**Важно:** репозиторий `nadigrbt/project` публичный, и через GitHub Pages всё содержимое папки видно по адресу `nadigrbt.github.io/project/Sayvo/`. Код приложения и контент лучше хранить в отдельном приватном репозитории.
