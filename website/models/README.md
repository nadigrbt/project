# Модели вещей

Положите сюда GLB-файлы и опишите их в `manifest.json`. Вещи из манифеста заменят встроенные заглушки, остальные останутся как есть. Если манифеста нет, сайт работает на заглушках.

## Слоты

`tote`, `sneaker`, `chunkySneaker`, `perfume`, `sunglasses`, `headphones`, `earbuds`, `smartwatch`, `backpack`, `wallet`, `lipstick`, `camera`, `cap`, `skateboard`, `vinyl`, `controller`, `tumbler`, `phone`, `speaker`, `crossbody`, `chain`, `perfume2`, `letterS`

## Пример `manifest.json`

```json
{
  "sneaker": { "file": "sneaker.glb", "size": 1.9 },
  "perfume": { "file": "perfume.glb", "size": 1.4, "rotation": [0, 1.57, 0] },
  "camera": "camera.glb"
}
```

- `file` — имя файла в этой папке.
- `size` — размер большей стороны модели в условных единицах (по умолчанию как у заглушки, 1–2).
- `rotation` — поворот в радианах, если модель стоит «не так».

## Фото вместо 3D-модели

Если 3D-модели нет, вещь можно заменить фотографией с прозрачным фоном (PNG). Положите файл в папку `website/images/` и укажите его через `image`:

```json
{
  "sunglasses": { "image": "sunglasses.png", "size": 2.0 }
}
```

Фото всегда повёрнуто к зрителю, но «разворачивается», покачивается и раскручивается от свайпа, как остальные предметы. `size` здесь задаёт ширину (для вытянутых вверх фото — высоту). Хорошо работают фото одним предметом, обрезанные по краю, шириной до 1024 px.

## Лицензии

Используйте только модели и фото, на которые у вас есть права: свои, купленные, заказанные или с открытой лицензией (CC0, CC-BY). Для CC-BY добавьте автора ниже.

| Слот | Источник | Лицензия | Автор |
| --- | --- | --- | --- |
| `sunglasses`, `chain`, `chunkySneaker` | Фото, предоставленные заказчиком | Права нужно подтвердить | Не указан |
| `sneaker`, `perfume`, `perfume2`, `tote`, `letterS` | Фото, предоставленные заказчиком (товарные фото брендов и стеклянная буква) | Права нужно подтвердить: на фото видны логотипы и товарные знаки | Не указан |
