# Основа — вариант 1
Статический адаптивный сайт. Для просмотра запустите `python -m http.server 8000 --directory dist`.
Тексты и фотографии: `dist/app.js` и `dist/*.png`. Стили: `dist/style.css`.
Маршруты: главная, дома, бани, гаражи, портфолио, объект, стоимость, отзывы, контакты.
Форма демонстрационная: проверяет обязательные поля, ничего не отправляет и не хранит.
Название и объекты демонстрационные. Реальные контакты, адрес, отзывы и сметные ориентиры нужно заменить перед запуском.
Для заявок нужен серверный обработчик и почта/мессенджер; для самостоятельного редактирования контента нужна CMS. В текущей версии изменение выполняется в исходниках.
