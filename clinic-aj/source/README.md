# Сайт клиники A&J (clinic-aj.ru)

Сайт перенесён с Тильды на код. Сделан на [Astro](https://astro.build): на выходе получаются обычные HTML-файлы, которые можно положить на любой хостинг, в том числе Timeweb.

## Что где лежит

```
src/
  data/
    site.ts       ← телефон, адреса, соцсети, ссылка на онлайн-запись, реквизиты
    services.ts   ← блок «Наши услуги» на главной
    images.ts     ← список всех картинок
  components/     ← блоки страницы: шапка, первый экран, услуги, контакты, подвал…
  layouts/Base.astro ← общий каркас: мета-теги, Метрика, версия для слабовидящих, cookie
  pages/          ← страницы сайта (index.astro = главная)
  styles/global.css ← цвета, шрифты, общие стили
public/
  .htaccess       ← адреса без .html, https, кэш
  api/send.php    ← отправка формы «Хотите задать вопрос?»
  api/config.php  ← куда слать заявки (Telegram и/или почта)
  images/         ← картинки (появятся после `npm run images`)
scripts/fetch-images.mjs ← скачивает картинки с Тильды
```

Поменять телефон или адрес — правка в одном месте, `src/data/site.ts`.

## Как запустить у себя

1. Установите Node.js версии 20 или новее: https://nodejs.org (кнопка LTS).
2. Откройте папку проекта в терминале и выполните:

```bash
npm install        # один раз — установит зависимости
npm run images     # один раз — скачает картинки с Тильды в public/images
npm run dev        # запустит сайт на http://localhost:4321
```

Пока работает `npm run dev`, любые правки в файлах сразу видны в браузере.

## Как выложить на Timeweb

1. Соберите сайт: `npm run build`. Появится папка `dist/`.
2. В панели Timeweb откройте «Файловый менеджер» → папку сайта `public_html`.
3. Загрузите туда **содержимое** папки `dist/` (не саму папку). Убедитесь, что скрытые файлы `.htaccess` тоже загрузились.
4. Откройте `public_html/api/config.php` и впишите токен Telegram-бота и/или почту для заявок (инструкция внутри файла).
5. В настройках сайта на Timeweb включите бесплатный SSL-сертификат.

> Переключать домен с Тильды стоит, когда будут перенесены все страницы (сейчас готова только главная), иначе ссылки на услуги будут вести в пустоту.

## Шрифт

На Тильде был GT Eesti Pro — платный шрифт, который Тильда даёт только внутри своих сайтов. Здесь вместо него стоит Jost: он бесплатный, похож по характеру и хранится прямо на сайте (без Google Fonts). Если купите лицензию на GT Eesti Pro — замену можно сделать в `src/styles/global.css`.
