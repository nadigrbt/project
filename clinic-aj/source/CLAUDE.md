# Сайт клиники A&J (clinic-aj.ru)

Перенос сайта клиники эстетической косметологии A&J (Мурманск) с Тильды на код.
Владелец — Надежда, не программист: объясняй простыми словами, команды давай готовыми к копированию.

## Стек
- Astro, статическая сборка (`npm run build` → `dist/`), хостинг Timeweb (Apache, `public/.htaccess`).
- Адреса страниц как на Тильде: `/lpg`, `/smas` … (`build.format: 'file'` + rewrite в .htaccess).
- Форма «Задать вопрос» → `public/api/send.php` (Telegram и/или почта, настройки в `public/api/config.php`).
- Яндекс.Метрика 94733259, виджет для слабовидящих lidrekon, cookie-плашка — в `src/layouts/Base.astro`.
- Картинки: `npm run images` скачивает их с Тильды в `public/images` (список в `src/data/images.ts`).

## Где что
- `src/data/site.ts` — телефон, адреса, соцсети, ссылка на онлайн-запись (Taplink), реквизиты.
- `src/data/services.ts` — блок «Наши услуги» на главной.
- `src/components/` — блоки главной; `src/styles/global.css` — цвета, шрифты, размеры.

## Решения, принятые с владельцем
- Палитра сайта — только 4 цвета (токены в global.css): Ivory #F1EAE0, White #FFFFFF, Wine #784443, Graphite #262323. Новые цвета не добавлять.
- Шрифты: заголовки, меню, кнопки — Jost (`--font`); основной текст — Commissioner (`--font-text`), размер `--text: 18px`.
  GT Eesti Pro (как на Тильде) платный — подключится сам, если положить woff2 в `public/fonts`.
- Галочка согласия на обработку ПД по умолчанию снята (152-ФЗ).
- Сейчас главная — точная копия Тильды. Остальные ~45 страниц ещё не перенесены; домен не переключать, пока не перенесены все.

## Редизайн (следующий шаг)
Три варианта главной нарисованы на холсте: https://claude.ai/artifact/RsFcK5VzUeDbtgaEcnUWc8
- A «Ателье» — тихая роскошь, арка с фото врачей, карточки услуг с ценой «от …».
- B «Подбор по задаче» — первый экран «Что вы хотите изменить?» с интерактивным подбором процедур.
- C «Монограмма» — тёмная смелая версия.
Ждём выбор владельца, затем переносим выбранный вариант в код.
Нужны от владельца: реальные цены, имена и стаж врачей, отзывы (только настоящие, с Яндекс Карт/2ГИС).
Ничего не выдумывать: где нет фактов — ставить заглушки вида [цена].
